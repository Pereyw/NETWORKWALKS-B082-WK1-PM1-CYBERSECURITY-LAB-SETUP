# NETWORKWALKS-B082-WK1-PM1-CYBERSECURITY-LAB-SETUP
This project focus on setting up a virtual cybersecurity and Penetration-testing laboratory using VirtualBox and Kali Linux

The purpose of the lab is to create a controlled environment where cybersecurity tools, network scanning, reconnaissance, vulnerability assessment, and other security-testing activities can be performed safely and repeatedly

The lab is configured in a private virtual network so that additional machines can be added later and used as targets for authorized security testing
